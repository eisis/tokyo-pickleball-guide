### 7「服装と持ち物」の確定版

スライドの構成は次の7枚です。表紙は黄色（SUN）背景にして、青い表紙が続いていたグリッドの中でひと目で区別できるようにしました。
1. 表紙（黄色）：保存版／はじめての人へ／何、着ていく？何、持っていく？／ピックルボールの服装と持ち物、ポロ・帽子・ボトル・運動靴・タオル・パドルの平置き
2. 服は、動きやすければOK：いつものTシャツやジャージで大丈夫、男女2人の立ち姿
3. 靴は、ふだんの運動靴でOK：サンダルや革靴は避ける、運動靴○／サンダル×／革靴×
4. 屋内コートは、靴の決まりを確認：室内用の運動靴が必要なところも、木の床にシューズ袋と室内用の靴
5. パドルは、借りられる：施設によっては靴まで借りられる、「レンタルOK」「手ぶらで行けるところも」
6. あると安心：飲み物・タオル・帽子（屋外）
7. 持ち物チェックリスト（紺）：動きやすい服／運動靴（屋内は室内用も）／飲み物／タオル／帽子（屋外）、プロフィールのリンク

事実の確認：テニスシューズ必須の施設は見つからず、イベントの持ち物はどこも「運動靴」（屋外用・室内用）。Sansanピックルボールコート池袋はパドル・シューズ・ウェアを1時間各500円で貸し出し（Oggi 2026-07-24）。「テニスシューズがおすすめ」は入れない。

キャプションです。

```
ピックルボール、何を着ていく？何を持っていく？🎾

はじめて行く前に、気になるのが服装と持ち物。
実は、特別なものはほとんどいりません。

服は、動きやすければOK。いつものTシャツやジャージで大丈夫です。
靴も、ふだんの運動靴で大丈夫。サンダルや革靴は避けましょう。
屋内の施設は、室内用の靴が必要なところもあるので、予約のときに確認しておきましょう。

パドルは借りられるコートが多く、施設によっては靴まで借りられます。
手ぶらで行けるところもあるので、気軽に試してみてください。
あとは飲み物とタオル、屋外なら帽子があれば安心です。

あとで見返せるように、保存しておいてください。
レンタルのあるコートや体験会は、プロフィールのリンク（pickleball-tokyo.com）から探せます。

#ピックルボール #ピックルボール初心者 #ピックルボール東京 #ピックルボール持ち物 #pickleballtokyo
```

### 6「運動が苦手でも、ピックルボールってできる？」の確定版

スライドの構成は次の7枚です。
1. 表紙：はじめての人へ／運動が苦手でも、ピックルボールってできる？／できる理由が、4つあります
2. 理由1 コートが小さい：テニスコートと重ねた図、「ピックルボールコートは、約3分の1」（公式寸法から計算）
3. 理由2 ボールがゆっくり：テニス「ビュン！」とピックルボール「ふわっ」の比較
4. 理由3 サーブは下から：横向きの人、腰の高さの線、腰より下で打つ
5. 理由4 ネットの手前で、スマッシュできない：半面の図、オレンジのキッチン、ノーバウンドNG／OK、「※キッチンに入るのはOK」
6. だから、どの世代でも、一緒に楽しめる：シニア・女性・男性・少年の4人（襟付きポロ）
7. まずは、1回やってみよう：プロフィールのリンク、pickleball-tokyo.com、「運動が苦手な友達にも、送ってみてね」

サイト記事（/blog/beginner-friendly/）では、コートの広さ・キッチン・下からのサーブ・全世代の根拠に USA Pickleball（https://usapickleball.org/what-is-pickleball/）を引用しています（20×44フィート、7フィートのキッチン、腰より下のアンダーハンドサーブ、"accessible to all ages and abilities"）。

キャプションです。

```
運動が苦手でも、ピックルボールってできる？🎾

「スポーツはちょっと…」という人にこそ、知ってほしいのがピックルボールです。

コートはテニスの約3分の1の広さで、走り回らなくても大丈夫。
ボールはゆっくり飛ぶので、目で追いやすい。

子どもからシニアまで、いろいろな世代が同じコートで一緒に楽しめるのも魅力です。
はじめての日から、ラリーを楽しめる人が多いスポーツです。

まずは1回、やってみませんか？
初心者向けの体験会や、道具を借りられるコートは、プロフィールのリンク（pickleball-tokyo.com）から探せます。
運動が苦手な友達にも、送ってみてください！

#ピックルボール #ピックルボール初心者 #ピックルボール東京 #運動不足解消 #pickleballtokyo
```

## 次の投稿の候補（話し合い済み）

- 1人いくらで遊べる？：4人・1時間・レンタル込みで1人あたりを計算します。安い例はWELL平日1,250円・VIP東陽町1,320円、高い例はSansan池袋・SEIBU品川で「高くても1人3,000円以下」。作る前に公式料金を再確認すること。
- 点数の数え方（「0-0-2」って何の数字？）、えっ、こんな所で？東京の意外なコート（サイト掲載分から）、テニスコート1面にピックルボールコートは何面入る？
- 1人でも行ける？（オープンプレイ・体験会）、テニス・卓球・バドミントンとの違い、エリア別コートマップ、最初に覚える用語3つ、マイパドルの選び方。
- 不評だった案：名前の由来（へえで終わる）、OK？NG？ルールクイズ（既視感）。ユーザーが求めるのは「役に立つ」かつ「興味深い」もの。

## 作り方の決まり

- 方針は、一流の専門家（SNS運用・コンテンツクリエイター・コピーライター・デザイナー・企画者・ファッションコーディネーターなど）で議論して決めます。論点・反論・結論を短く示します。
- 画像を作る前に、スライドごとの文言とキャプションを先に固めます（トークン節約）。
- 事実は公式情報で確かめられたものだけを使います。数字は出典がないものは入れません（例：世代の話は「いろいろな世代」で、年齢の数字は入れない）。
- 初心者目線で書く：初心者が持っていない物（例：テニスシューズ）を前提にしない。
- ハッシュタグは5個まで（Instagramの上限）。基本は #ピックルボール #ピックルボール初心者 #ピックルボール東京 #pickleballtokyo ＋テーマの1個。
- 投稿したら、内容に合わせてサイトに記事を追加します（太字や箇条書きに頼らない自然な文体）。記事のカバーは投稿の表紙画像（coverFit: contain）で、本文に投稿のスライド画像を入れてもよい。日付ものの記事は「◯月◯日時点」を明記する。
- プロフィールのリンクはUTM付き：`?utm_source=instagram&utm_medium=social&utm_campaign=profile`

## デザインのルール（指摘から学んだこと）

- 表紙は、投稿欄（グリッド）でぱっと見て何の投稿か分かるようにする。前の投稿と背景色を変え、テーマそのものの絵（持ち物なら道具の平置き）を大きく入れる。パドルとボールだけの表紙を続けない。
- 渡す前に、文字と絵の重なり・切れ・端へのはみ出しを、全体と拡大の両方で必ず確認します。
- 文字は大きめにします：見出し96px、本文46px、1枚の本文は2〜3行まで。
- 点線や残像で動きを表さない。軌道は、太さと濃さが増していくなめらかな光の帯で描きます。
- 飾りのきらきら・意味のない下線は入れません。
- 白いカードの上に白い物（白い靴底・白いラベル）を置くと消えるので、ふちの色やラベルの色を変える。
- 人のイラストの作り方です。
  - 顔は点の目・にっこり口・ほっぺを描く（のっぺらぼうは気持ち悪い）。
  - 首は頭に合わせて太く、腕は左右同じ長さにします。
  - シャツは胴と袖を1つの形で描き、なで肩にする（パーツを重ねると切れ目やこぶが出る）。
  - 服は襟付きポロ。色はサイトと同じ紺・コーラル・イエロー・白で、背景とトーンをそろえる（パステルは浮く）。
  - 帽子のつばは本体とつなげて描く。立ち位置は等間隔にする。
- 色は NAVY(14,52,82) / SEA(31,127,184) / CORAL(255,107,74) / SUN(255,214,120) / SAND(246,236,216) / KIT(24,168,150)、キッチンはオレンジ(246,136,56)。
- 1080×1350、Noto Sans CJK。フッターに「PICKLEBALL TOKYO」と「n/N @pickleballtokyo」。
- 絵文字はテニスの🎾（🏓は卓球なので使わない）。
